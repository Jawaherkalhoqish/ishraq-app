Ishraq
Project Overview
Ishraq is an adaptive gamified learning platform designed to support children aged 6–9 in developing basic mathematical skills and improving attention through interactive and engaging learning experiences.
The platform combines educational activities with game-based learning to create a child-friendly environment that encourages participation, practice, and continuous learning.
Problem Statement
Traditional learning approaches may not always provide children with an engaging environment that supports both learning and sustained attention.
Ishraq addresses this challenge by providing an interactive digital learning experience that transforms educational activities into engaging and age-appropriate experiences.
Proposed Solution
Ishraq provides a gamified learning environment where children can interact with educational activities designed to support their learning and engagement.
The platform focuses on:
Developing basic mathematical skills through interactive activities.
Encouraging attention and active participation.
Providing an engaging and child-friendly learning experience.
Supporting a more personalized learning journey.
Tracking learning progress and performance.
Key Features
Gamified Learning
Educational content is presented through interactive game-based activities to make the learning experience more engaging.
Adaptive Learning
The platform is designed to provide an adaptive learning experience based on the child's performance and learning needs.
Mathematics Activities
Interactive activities are designed to help children practice and strengthen their basic mathematical skills.
Attention and Engagement
The activities encourage children to remain focused and actively engaged throughout the learning experience.
Progress Tracking
The platform supports monitoring the child's performance and learning progress over time.
Target Users
Ishraq is designed primarily for:
Children aged 6–9.
Parents and caregivers.
Teachers and educators.

Design Approach
The platform follows a child-centered design approach, focusing on simplicity, accessibility, intuitive navigation, and engaging interactive elements.
The interface was designed to provide children with a clear and enjoyable learning environment while maintaining a structured educational experience.
Project Purpose
Ishraq was developed as an academic project to explore the use of adaptive learning and gamification in supporting children's mathematical learning and attention.
