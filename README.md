# ✨ Ishraq | إشراق

### Adaptive Gamified Learning Platform for Children

Ishraq (إشراق) is an interactive and adaptive learning platform designed for children aged 6–9. It combines educational activities with gamification to create an engaging and child-friendly learning experience.

The platform focuses on supporting the development of basic mathematical skills and attention through interactive activities and personalized learning experiences.

---

## 🎯 Problem

Traditional learning methods may not always provide children with an engaging environment that supports both learning and sustained attention.

Ishraq addresses this challenge by transforming educational activities into interactive and game-based experiences that encourage children to learn, practice, and stay engaged.

---

## 💡 Solution

Ishraq provides a gamified learning environment where children can learn through interactive activities while receiving an experience designed around their performance and learning needs.

The platform aims to make learning more enjoyable, engaging, and accessible for young learners.

---

## 🚀 Key Features

- 🎮 **Gamified Learning**  
  Interactive game-based activities that make learning more engaging.

- 🧠 **Adaptive Learning**  
  Learning experiences designed to adapt to the child's performance and needs.

- 🔢 **Mathematics Activities**  
  Interactive activities that support the development of basic mathematical skills.

- 🎯 **Attention & Engagement**  
  Activities designed to encourage focus and active participation.

- 📊 **Progress Tracking**  
  Monitoring the child's performance and learning progress.

- 🌈 **Child-Friendly Design**  
  A simple, intuitive, and engaging interface designed for young learners.

---

## 👥 Target Users

- 👦 Children aged 6–9
- 👨‍👩‍👧 Parents and caregivers
- 👩‍🏫 Teachers and educators
